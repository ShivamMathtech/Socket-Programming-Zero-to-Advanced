# Community code of conduct

Treat learners, maintainers and reviewers with respect. Welcome beginner questions
and different backgrounds. Discuss code and ideas without personal attacks.
Harassment, threats, discriminatory remarks, deliberate humiliation and sharing
someone else's private information are unacceptable.

When reviewing, describe the behavior you observed, explain the consequence and
suggest a constructive change. When reporting a concern, use the repository
host's private reporting tools or contact the actual repository maintainer through
their published channel. No contact address is invented in this distribution.

Maintainers may edit or remove abusive content, restrict participation or remove
access. Apply responses proportionally and explain decisions where doing so does
not expose private information. This code applies to repository discussions,
issues, pull requests and associated learning spaces.
